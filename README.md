# 初動率計算機

自分のデッキで「最初の手札で動ける確率（初動率）」を計算する、遊戯王 OCG の非公式ツールです。
ブラウザで開くだけで使えます。インストールや登録はいりません。

**[初動率計算機を開く](https://toshiaki1729.github.io/yugioh-consistency-calculator/)**

## 使い方

1. **デッキを入れる**
   「デッキ」タブで、公式カードデータベース（遊戯王ニューロン）からデッキを取り込みます。カード名を検索して、1 枚ずつ入れることもできます。
2. **初動のカードをまとめる**（必要なときだけ）
   「カードグループ」タブで、「○○」モンスター、魔法・罠、レベル 4 以下など、同じ役割のカードをまとめます。
3. **初動の組み合わせを登録する**
   「初動パターン」タブで、「このカード 1 枚」「このグループから 1 枚＋あのカード 1 枚」など、初動になる手札の組み合わせを登録します。
4. **計算する**
   「計算する」を押すと、先攻（5 枚）と後攻（6 枚）の初動率が表示されます。

《成金ゴブリン》や《強欲で貪欲な壺》などのドローカードも、「ドロー効果」タブで登録すれば計算に含められます。

## 注意点

- 計算の対象はメインデッキだけです。
- 計算するのは「最初の手札に、登録した組み合わせがそろう確率」だけです。相手の妨害や、ルール上その展開ができるかどうかは判定しません。
- デッキのデータは、今使っているブラウザの中にだけ保存されます。消えると困るデッキは、「JSON 書き出し」でファイルに保存しておいてください。
